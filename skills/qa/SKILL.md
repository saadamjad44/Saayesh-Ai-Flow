# QA Skill

Use before launch and after significant changes.

## Check
- Build/lint/tests
- Routes and links
- 404s and obvious broken assets
- Mobile/responsive layout
- Metadata/canonical/indexability
- Sitemap and robots
- Structured data where applicable
- Accessibility basics
- Performance regressions

## Reporting
Return:
- Passed checks
- Problems found
- Fixes made
- Remaining risks
