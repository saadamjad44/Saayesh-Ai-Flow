# Website Engineering Skill

Use for building and modifying the Saayesh Automate Stack website.

## Before coding
- Inspect the existing project.
- Read the relevant `revised-blueprint-phase1.jsx` section.
- Confirm the Phase 1 page being implemented.
- Reuse existing components and patterns.

## Engineering priorities
1. Correctness
2. Accessibility
3. Responsive UX
4. Performance
5. SEO/indexability
6. Maintainability

## Guardrails
- Avoid unnecessary dependencies.
- Keep components reusable.
- Keep source files reasonably sized.
- Preserve stable URLs and approved architecture.
- Run build/lint/tests after meaningful changes.
