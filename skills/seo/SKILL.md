# SEO Skill

Use for technical SEO, on-page SEO, schema, internal linking, indexability, and SEO audits.

## Procedure
1. Inspect the page/site and relevant blueprint section.
2. Identify search intent and primary keyword from approved data.
3. Check crawlability, canonicals, metadata, headings, internal links, structured data, sitemap, robots, and indexability.
4. Implement only evidence-based improvements.
5. Run build/tests and report issues fixed.

## Guardrails
- Never invent SEO metrics.
- Do not keyword-stuff.
- Do not create duplicate or near-duplicate pages just to target keyword variants.
- Preserve approved URL structure unless a change is explicitly requested.
